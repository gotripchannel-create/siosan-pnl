# СИОСАН — Управленческий P&L

React/Vite + Supabase + Vercel.

## Вставка отчёта из ВК

В разделе «Входящие отчёты» сотрудник копирует сообщение из рабочего чата ВК и вставляет его в приложение. Парсер разбирает выручку, покупки, другие расходы, курьера, авансы и смены. Перед применением пользователь проверяет данные; при расхождении с указанным итогом выручки применение блокируется.

Автоматический VK API-бот в этой версии не используется.
