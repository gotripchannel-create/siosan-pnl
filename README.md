# СИОСАН — Управленческий P&L

Готовый React/Vite-проект для публикации на Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Публикация на Vercel

1. Откройте https://vercel.com/new
2. Импортируйте этот проект через GitHub или загрузите его в репозиторий.
3. Vercel автоматически определит Vite.
4. Нажмите Deploy.

Данные сохраняются в localStorage браузера. Это означает, что у каждого браузера/устройства своя локальная база.
Для общей базы между несколькими сотрудниками потребуется подключить облачное хранилище/БД (например, Supabase).
